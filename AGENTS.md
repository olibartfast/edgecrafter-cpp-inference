## Build
- ONNX Runtime is the default backend. TensorRT is also supported when built with `-DUSE_ONNX_RUNTIME=OFF -DUSE_TENSORRT=ON -DTENSORRT_DIR=/path/to/TensorRT`.
- CMake auto-downloads ONNX Runtime 1.21.0 into `build/_deps` on first configure.
- `cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release && cmake --build build --parallel`

- Format apply: `find src -name '*.cpp' -o -name '*.hpp' | xargs clang-format-18 -i`

## Architecture
- Entry point: `src/main.cpp` → `EdgeCrafterInference` in `src/edgecrafter_inference.{hpp,cpp}`
- Backend interface: `src/backends/inference_backend.hpp`, implemented by `onnx_runtime_backend.{hpp,cpp}` and `tensorrt_backend.{hpp,cpp}`
- Processing utilities: `src/processing_utils.{hpp,cpp}` (preprocessing, color generation, keypoint drawing)

## Usage
| Task | Flag | Output tensors |
|------|------|----------------|
| Detection | _(default)_ | labels, boxes, scores |
| Segmentation | `--segmentation` | labels, boxes, scores, masks |
| Pose estimation | `--pose` | labels, scores, keypoints |

- `--pose` additionally sets `label_offset=-1` because the pose model outputs label 1 for person (not 0).
- The C++ side derives bounding boxes from visible keypoints for pose when boxes are absent.
- All class label indices are from `data/coco.names` (80 COCO classes, 0-indexed from the file).
- Threshold: `--threshold <value>` (default 0.5).
- Output path: `--output <path>`.

## Drawing behavior
- For segmentation: masks are alpha-blended at 45% onto the image first, then box/text annotations are drawn at 100% opacity on top. Detection and pose draw everything at full opacity.
- Per-class colors are generated by `get_color_for_class()` which uses HSV with a golden-angle hue distribution (`S=200,V=200`). If mask colors are hard to distinguish, adjusting saturation/value there is the fix.
